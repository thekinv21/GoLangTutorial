## Что такое Go (Golang)?

Go — это открытый, статически типизированный, компилируемый язык программирования, представленный Google в 2009 году. Он создан для разработки быстрых и простых программ, хорошо справляющихся с конкурентными задачами.

## Установка Go

Скачай установщик для своей операционной системы с [go.dev/dl](https://go.dev/dl) и установи его.

- **Windows:** Запусти файл `.msi`.
- **macOS:** Запусти файл `.pkg` или выполни `brew install go`
- **Linux:** Распакуй архив `.tar.gz` в `/usr/local` и добавь `/usr/local/go/bin` в PATH.

Проверь:

```bash
go version
```

## Первый проект

```bash
mkdir privet && cd privet
go mod init privet
```

`main.go`:

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет, Go!")
}
```

```bash
go run main.go
```

**Редактор:** VS Code + официальное расширение Go

## Для чего используется Go?

- **Backend и REST API:** Аутентификация, CRUD и работа с базами данных.
- **Микросервисы:** Разделение больших приложений на небольшие независимые сервисы.
- **Cloud и DevOps:** Docker, Kubernetes и Terraform написаны на Go; он идеален для CLI-утилит.
- **Конкурентные системы:** Одновременная обработка множества запросов и соединений.

## Преимущества

- Высокая производительность
- Простая конкурентность с помощью горутин
- Простой синтаксис
- Статическая типизация
- Лёгкое развёртывание одним бинарным файлом
- Мощная стандартная библиотека и инструменты

## Недостатки

- **Повторяющаяся обработка ошибок:** Исключений нет; постоянно приходится писать `if err != nil`.
- **Ограниченные дженерики:** Появились в 1.18, но проще, чем в Java и C#.
- **Нет классов и наследования:** Тем, кто привык к ООП, нужно перестроить мышление.
- **Отсутствующие возможности языка:** Нет enum, тернарного оператора (`? :`) и параметров по умолчанию.
- **Меньшая экосистема:** Готовых библиотек и фреймворков меньше, чем у Java и Node.js.
- **Сборщик мусора:** Для систем реального времени и низкоуровневых задач (игровые движки, встраиваемые системы) лучше подходят Rust или C++.
- **Слаб во frontend и GUI:** Редко выбирается для разработки десктопных и мобильных интерфейсов.
- **Ошибки nil pointer:** При невнимательности во время выполнения может возникнуть `panic`.

## Go vs Java vs C# vs Node.js

| Характеристика            | Go                           | Java                               | C#                                           | Node.js                                 |
| ------------------------- | ---------------------------- | ---------------------------------- | -------------------------------------------- | --------------------------------------- |
| **Тип**                   | Язык программирования        | Язык программирования              | Язык программирования                        | Среда выполнения JavaScript             |
| **Выполнение**            | Компилируется в машинный код | Байт-код на JVM (JIT)              | На .NET CLR (JIT, есть поддержка AOT)        | JavaScript на V8                        |
| **Производительность**    | Высокая                      | Высокая, после прогрева            | Высокая                                      | Сильна в I/O, слаба в CPU-задачах       |
| **Время запуска**         | Очень быстрое                | Медленное                          | Среднее                                      | Быстрое                                 |
| **Конкурентность**        | Горутины, каналы             | Потоки, virtual threads (Java 21+) | async/await, Task                            | Event loop, async/await                 |
| **Потребление памяти**    | Низкое                       | Высокое                            | Среднее                                      | Среднее                                 |
| **Система типов**         | Статическая                  | Статическая                        | Статическая                                  | Динамическая (статическая с TypeScript) |
| **Синтаксис**             | Простой, мало ключевых слов  | Многословный                       | Богатый, много возможностей                  | Гибкий                                  |
| **Изучение**              | Легко                        | Средне–сложно                      | Средне                                       | Легко, если знаешь JavaScript           |
| **Популярные фреймворки** | net/http, Gin, Echo, Fiber   | Spring Boot, Quarkus               | ASP.NET Core                                 | Express, Fastify, NestJS                |
| **Развёртывание**         | Один бинарный файл           | Нужны JAR + JVM                    | .NET runtime или self-contained              | Нужны Node.js + node_modules            |
| **Сильные стороны**       | Микросервисы, cloud, CLI     | Корпоративные системы, банкинг     | Корпоративные системы, Windows, игры (Unity) | Real-time приложения, full-stack JS     |

**Итог:** Go даёт простоту и скорость. У Java и C# сильные экосистемы для крупных корпоративных проектов. Node.js позволяет использовать тот же язык, что и на frontend.
