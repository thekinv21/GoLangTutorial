# Пакет `fmt` в Go

## Что такое пакет `fmt`?

`fmt` (format) — это пакет для операций **ввода/вывода (I/O)**. Он похож на функции `printf` и `scanf` из языка C, но спроектирован с учётом системы типов Go. Чтобы им пользоваться, достаточно импортировать пакет:

```bash
import "fmt"
```

Функции делятся на группы по названию:

| Префикс / Суффикс                   | Значение                                                        |
| ----------------------------------- | --------------------------------------------------------------- |
| `Print...`                          | Пишет в стандартный вывод (`os.Stdout`)                         |
| `Sprint...`                         | Возвращает результат как `string`                               |
| `Fprint...`                         | Пишет в любой `io.Writer`                                       |
| `Append...`                         | Добавляет результат в срез `[]byte` (Go 1.19+)                  |
| `Scan...` / `Sscan...` / `Fscan...` | Читают соответственно из stdin, из строки и из `io.Reader`      |
| `...ln`                             | Добавляет перевод строки в конце (при чтении — останавливается на конце строки) |
| `...f`                              | Использует строку формата (format string)                       |

## Вывод на экран: `Print`, `Println`, `Printf`

```bash
fmt.Print("Hello","World") --> Результат: HelloWorld

fmt.Print(1,2) --> Результат: 1 2

fmt.Println("Hello","World") --> Результат: Hello World\n

fmt.Printf("Age: %d\n", 20) --> Результат: Age: 20
```

ПРИМЕЧАНИЕ:

- **Print** — выводит значения подряд, пробел между двумя значениями добавляет только если **ни одно из них не строка**, и не добавляет перевод строки (**\n**) в конце
- **Println** — всегда добавляет пробел между значениями и перевод строки (**\n**) в конце
- **Printf** — принимает строку формата и не добавляет перевод строки, его нужно дописывать вручную

Все три возвращают **(n int, err error)**: количество записанных байт и возможную ошибку. При выводе на экран эти значения обычно игнорируют.

### Общие глаголы (verbs)

| Глагол | Описание                        | Пример вывода                     |
| ------ | ------------------------------- | --------------------------------- |
| `%v`   | Формат по умолчанию             | `{Ali 30}`                        |
| `%+v`  | Структура с именами полей       | `{Name:Ali Age:30}`               |
| `%#v`  | Представление в синтаксисе Go   | `main.Person{Name:"Ali", Age:30}` |
| `%T`   | Тип значения                    | `main.Person`                     |
| `%%`   | Сам знак процента               | `%`                               |

### Глаголы для целых чисел

| Глагол      | Описание                                      | Для `42`    |
| ----------- | --------------------------------------------- | ----------- |
| `%d`        | Десятичная система                            | `42`        |
| `%b`        | Двоичная система                              | `101010`    |
| `%o`        | Восьмеричная система                          | `52`        |
| `%O`        | Восьмеричная с префиксом `0o`                 | `0o52`      |
| `%x` / `%X` | Шестнадцатеричная (строчные / заглавные)      | `2a` / `2A` |
| `%c`        | Символ Unicode                                | `*`         |
| `%q`        | Символ в одинарных кавычках                   | `'*'`       |
| `%U`        | Формат Unicode                                | `U+002A`    |

### Глаголы для чисел с плавающей точкой

| Глагол      | Описание                                                    | Для `3.14159`           |
| ----------- | ----------------------------------------------------------- | ----------------------- |
| `%f` / `%F` | Десятичная запись                                           | `3.141590`              |
| `%e` / `%E` | Научная (экспоненциальная) запись                           | `3.141590e+00`          |
| `%g` / `%G` | `%e` или `%f` в зависимости от значения, без лишних нулей   | `3.14159`               |
| `%x`        | Шестнадцатеричная научная запись                            | `0x1.921f9f01b866ep+01` |

### Глаголы для строк и байтов

| Глагол | Описание                               | Для `"Go"` |
| ------ | -------------------------------------- | ---------- |
| `%s`   | Строка как есть                        | `Go`       |
| `%q`   | В двойных кавычках, с экранированием   | `"Go"`     |
| `%x`   | Шестнадцатеричный вид по байтам        | `476f`     |

### Глаголы для boolean и указателей

| Глагол | Описание           | Пример вывода    |
| ------ | ------------------ | ---------------- |
| `%t`   | Логическое значение | `true` / `false` |
| `%p`   | Адрес в памяти     | `0xc000012345`   |

#### Указатели: `%p` → адрес в памяти, например 0xc000012345.

```bash
type Person struct {
	Name string
	Age int
}

myPerson := Person{"Vadim", 26}

fmt.Printf("%v\n", myPerson) --> Результат: {Vadim 26}

fmt.Printf("%+v\n", myPerson) --> Результат: {Name:Vadim Age:26}

fmt.Printf("%#v\n", myPerson) --> Результат: main.Person{Name:"Vadim", Age:26}

fmt.Printf("%T\n", myPerson) --> Результат: main.Person
```

## Формирование строк: `Sprint`, `Sprintln`, `Sprintf`

Эти функции работают как семейство Print, но вместо вывода на экран возвращают результат в виде **строки**

```bash
stringValue := fmt.Sprintf("%s, %d лет", "Vadim", 26) --> Результат: "Vadim, 26 лет"

totalValue := fmt.Sprint("Total:", 10) --> Результат: "Total:10"

uValue := fmt.Sprintln("a", "b") --> Результат: "a b\n"
```

Используются везде, где нужно собрать строку: сообщения логов, имена файлов, текстовые шаблоны

Семейство **Append** (Go 1.19+): добавляет данные в существующий срез []byte. Работает эффективно, так как не выделяет память под новую строку:

```bash
buf := []byte("Total: ")
buf = fmt.Appendf(buf, "%d", 42) --> Результат: "Total: 42"
```

## Запись в другие места: `Fprint`, `Fprintln`, `Fprintf`

Первым параметром они принимают **io.Writer**. Писать можно во всё, у чего есть метод **Write** (файл, сетевое соединение, HTTP-ответ, буфер):

```bash
// Запись в стандартный поток ошибок

fmt.Fprintln(os.Stderr, "произошла ошибка")

// Запись в файл:

newFile, err := os.Create("newFile.txt")
if err != nil {
	log.Fatal(err)
}
defer newFile.Close()

fmt.Fprintf(newFile, "Row %d\n", 1)

// Запись в HTTP-ответ

func handler(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintf(w, "Hello, %s!", r.URL.Path[1:])
}

// Запись в буфер

var newBuffer strings.Builder
fmt.Fprintf(&newBuffer, "%d-%d", 1, 2)
```

На самом деле **Printf** — это просто сокращение для **Fprintf(os.Stdout, ...)**

## Создание ошибок: `Errorf`

**Errorf** создаёт значение error с отформатированным сообщением:

```bash
err := fmt.Errorf("пользователь %d не найден", id)
```

Оборачивание ошибок с помощью **%w** (Go 1.13+): этот глагол сохраняет исходную ошибку, поэтому до неё можно добраться через **errors.Is** и **errors.As**:

```bash
_, err := os.Open("missing.txt")

if err != nil {
	err = fmt.Errorf("не удалось прочитать конфигурацию: %w", err)
}

if errors.Is(err, os.ErrNotExist) {
	fmt.Println("Файл не найден") // сработает
}
```

- Если использовать **%v**, сообщение будет выглядеть так же, но цепочка оборвётся, и errors.Is больше не найдёт совпадения.
- Начиная с Go 1.20, в одном Errorf можно использовать несколько **%w**
- Для фиксированных сообщений проще использовать **errors.New("...")**

## Чтение ввода пользователя: `Scan`, `Scanln`, `Scanf`

Эти функции возвращают значения через указатели, а также возвращают количество прочитанных значений и ошибку

```bash
var Name string
var Age int

// Scan: считает пробелы и переводы строки разделителями
n, err := fmt.Scan(&Name, &Age)

// Scanln: останавливается на переводе строки; все значения должны быть на одной строке
fmt.Scanln(&Name, &Age)

// Scanf: читает по заданному формату
fmt.Scanf("%s %d", &Name, &Age)
```

### Поведение функций чтения при переводе строки

| Функция  | Поведение при переводе строки                                                |
| -------- | ---------------------------------------------------------------------------- |
| `Scan`   | Считает перевод строки пробелом и продолжает, пока не прочитает все значения |
| `Scanln` | Останавливается в конце строки. Если значения не хватает, возвращает ошибку  |
| `Scanf`  | Переводы строки во вводе должны совпадать с теми, что в строке формата      |

**Важно:** семейство Scan разделяет слова по пробелам, поэтому **"Ali Veli"** нельзя прочитать в одну строку. Для чтения строк с пробелами используйте **bufio**

```bash
reader := bufio.NewReader(os.Stdin)
line, _ := reader.ReadString('\n')
line = strings.TrimSpace(line)

// или читаем построчно:

scanner := bufio.NewScanner(os.Stdin)

for scanner.Scan() {
	fmt.Println(scanner.Text())
}
```

Для чтения из **io.Reader** есть также **Fscan**, **Fscanln** и **Fscanf**

## Чтение из строки: `Sscan`, `Sscanf`

В качестве входных данных они принимают строку вместо stdin

```bash
var x, y int

fmt.Sscan("10 20", &x, &y)

var day, month, year int
fmt.Sscanf("17/10/26", "%d/%d/%d", &day, &month, &year)
```

## Итог

**Пакет `fmt`** — стандартный пакет Go для вывода на экран, формирования строк и чтения ввода пользователя.

### По названию функции можно понять, что она делает

- `Print` выводит на экран, `Sprint` возвращает строку, `Fprint` пишет в другое место, например в файл.
- Функции с окончанием `ln` добавляют перевод строки, с окончанием `f` используют строку формата (`%d`, `%s` и т. п.).
- Семейство `Scan` читает ввод пользователя, семейство `Sscan` читает из строки.
- `Errorf` создаёт отформатированное сообщение об ошибке. С `%w` исходная ошибка сохраняется.

### Самые используемые глаголы

- `%v` любое значение, `%+v` структура с именами полей, `%T` имя типа
- `%d` целое число, `%f` число с плавающей точкой, `%s` строка, `%t` boolean
- `%x` шестнадцатеричный вид, `%q` вид в кавычках

### Форматирование

`%8d` задаёт ширину, `%-8d` выравнивает по левому краю, `%05d` дополняет нулями, `%.2f` показывает два знака после запятой.

### Stringer

Если написать для типа метод `String() string`, `fmt` будет использовать его при выводе этого типа.

### На что обратить внимание

- `Printf` сам не добавляет перевод строки, не забывайте писать `\n`.
- При чтении передавайте адрес переменной: `fmt.Scan(&x)`.
- `Scan` останавливается на пробеле. Для чтения строки с пробелами используйте `bufio`.
- Не выводите то же значение через `%v` внутри его собственного метода `String()`, иначе программа уйдёт в бесконечную рекурсию.
- Запускайте `go vet`, чтобы находить ошибки форматирования.
