# Переменные в Go

Go — статически типизированный язык: тип каждой переменной известен на этапе компиляции и потом не меняется. Объявить переменную можно несколькими способами.

## 1. Объявление через var:

```bash
var fullName string = "Vadim Kiniabaev"
var age int = 26
```

- Если задать начальное значение, Go сам выведет тип (type inference):

```bash
var fullName = "Vadim Kiniabaev" (определяется как string)
var age = 21 (определяется как integer)
```

## 2. Короткое объявление: :=

- Самый распространённый способ внутри функций

```bash
 message := "Hello World"
 title := "Full-Stack Developer"
```

#### ПРИМЕЧАНИЕ:

:= можно использовать только внутри функции. На уровне пакета (вне функций) нужно использовать var.

## 3. Нулевые значения (zero values)

Переменные, объявленные без значения, автоматически получают нулевое значение своего типа. В Go не бывает «неопределённых» переменных:

| Тип                                           | Нулевое значение |
| --------------------------------------------- | ---------------- |
| `int`, `float64`                              | `0`              |
| `string`                                      | `""`             |
| `bool`                                        | `false`          |
| pointer, slice, map, channel, func, interface | `nil`            |

### Примеры

```bash
 var message string -> ""

 var price float64 -> 0

 var count int -> 0

 var isActive bool -> false
```

## 4. Множественное объявление

```bash
 var a,b,c int = 1,2,3

 var (
	user = "admin"
	port = 4200
	debug = false
 )
```

Обменять значения тоже можно в одну строку:

```bash
 a,b = b,a
```

## 5. Базовые типы

- **Целые числа:** int, int8, int16, int32, int64, для беззнаковых uint, uint8 (byte) и т. д.
- **Дробные:** float32, float64
- **Текст:** string, для одного символа rune (псевдоним int32)
- **Логический:** bool
- **Комплексные числа:** complex64, complex128

## 6. Преобразование типов

Go не преобразует типы автоматически, это нужно делать явно. Синтаксис всегда одинаковый: `T(значение)`

```bash
 var intNumber int = 20

 var floatNumber float64 = float64(intNumber)

 var uintNumber uint = uint(floatNumber)

 total := intNumber + floatNumber //ОШИБКА: int и float64 нельзя складывать

 total := float64(intNumber) + floatNumber // правильное использование
```

Даже типы из одного семейства не преобразуются автоматически:

```bash
var a int32 = 5
var b int64 = 7

sum := a + b        // ОШИБКА: int32 и int64 нельзя складывать
sum := int64(a) + b // правильное использование --> 12
```

### 6.1 Float → int: отбрасывание (без округления)

При преобразовании дробного числа в целое дробная часть **отбрасывается**, а не округляется:

```bash
f := 3.99
n := -3.99

int(f) --> 3
int(n) --> -3

int(math.Round(f)) --> 4 // для округления используется пакет math
```

### 6.2 Переполнение (overflow)

Если значение не помещается в целевой тип, Go не выдаёт ошибку, число **переходит через границу**:

```bash
big := 300
int8(big) --> 44 // диапазон int8: от -128 до 127

neg := -1
uint8(neg) --> 255 // uint8 не может быть отрицательным
```

#### ПРИМЕЧАНИЕ:

С константой вы получите ошибку компиляции: `int8(300)` --> "constant 300 overflows int8"

### 6.3 Строка ↔ число: пакет strconv

| Функция                       | Что делает                   | Пример                                                  |
| ----------------------------- | ---------------------------- | ------------------------------------------------------- |
| `strconv.Itoa(i)`             | int → string                 | `strconv.Itoa(20)` --> `"20"`                           |
| `strconv.Atoi(s)`             | string → int                 | `strconv.Atoi("123")` --> `123, nil`                    |
| `strconv.ParseInt(s, b, n)`   | string → int64 (основание b) | `strconv.ParseInt("ff", 16, 64)` --> `255`              |
| `strconv.ParseFloat(s, n)`    | string → float64             | `strconv.ParseFloat("3.14", 64)` --> `3.14`             |
| `strconv.ParseBool(s)`        | string → bool                | `strconv.ParseBool("true")` --> `true`                  |
| `strconv.FormatInt(i, b)`     | int64 → string (основание b) | `strconv.FormatInt(255, 2)` --> `"11111111"`            |
| `strconv.FormatFloat(f, ...)` | float64 → string             | `strconv.FormatFloat(3.14159, 'f', 2, 64)` --> `"3.14"` |

`Parse...` и `Atoi` всегда возвращают ещё и ошибку, не забывайте её проверять:

```bash
number, err := strconv.Atoi("abc")

if err != nil {
	fmt.Println(err) // strconv.Atoi: parsing "abc": invalid syntax
}

// при ошибке number равен 0
```

Чтобы вставить число в строку, можно также использовать **fmt.Sprintf**:

```bash
fmt.Sprintf("%d-%.1f", 7, 2.5) --> "7-2.5"
```

### 6.4 Частая ошибка: string(число)

`string()` не превращает число в текст, а воспринимает его как **код символа**:

```bash
x := 65

string(rune(x))  --> "A"  // 65 — это код буквы "A"
strconv.Itoa(x)  --> "65" // правильное использование
```

### 6.5 Строка ↔ []byte и []rune

```bash
[]byte("Go") --> [71 111]

s := "çay"
len(s)          --> 4 // количество байтов (ç занимает 2 байта)
len([]rune(s))  --> 3 // количество символов
```

Чтобы посчитать символы в тексте с турецкими или русскими буквами, используйте **[]rune**.

### 6.6 Нетипизированные константы (untyped constants)

Константы без явного типа получают тип там, где используются, преобразование не нужно:

```bash
const c = 10

var cf float64 = c --> 10 // преобразование не понадобилось
```

### Итог

| Преобразование       | Как сделать                           |
| -------------------- | ------------------------------------- |
| число → число        | `float64(x)`, `int(x)`, `int64(x)`    |
| число → строка       | `strconv.Itoa`, `strconv.FormatInt`   |
| строка → число       | `strconv.Atoi`, `strconv.ParseInt`    |
| строка → bool        | `strconv.ParseBool`                   |
| строка ↔ byte / rune | `[]byte(s)`, `[]rune(s)`, `string(b)` |

## 7. Константы: const

```bash
const Pi = 3.14159

const (
    Ponedelnik = iota  // 0
    Vtornik            // 1
    Sreda              // 2
)
```

**iota** — это счётчик, который увеличивается на единицу в каждой строке; идеально подходит для конструкций, похожих на enum.

## 8. На что обратить внимание

**Неиспользуемая переменная — это ошибка компиляции.** Go делает так намеренно, чтобы код оставался чистым:

```bash
x := 5   // Если x нигде не используется: ошибка "declared and not used"
```

### ПРИМЕЧАНИЕ:

Чтобы намеренно проигнорировать значение, используется \_ (blank identifier):

```bash
_, err := strconv.Atoi("123") // преобразованное число не используется, проверяется только ошибка
```

- **:=** требует хотя бы одну новую переменную. Если все переменные слева уже существуют, будет ошибка; если хотя бы одна новая, остальным просто присваивается значение.

- **Затенение (shadowing):** Использование := во внутреннем блоке не меняет внешнюю переменную, а создаёт новую:

```bash
x := 1

if true {
	x := 2 // новая x, не влияет на внешнюю
	fmt.Println(x) // здесь значение 2
}

// здесь значение 1, потому что **:=** во внутреннем блоке не меняет внешнюю переменную, а только создаёт новую
fmt.Println(x)
```

## 9. Видимость (Exported / Unexported)

Для переменных уровня пакета важна заглавная буква:

```bash
var Version string = "v1" // можно использовать как внутри, так и вне пакета

var newVersion string = "v2" // можно использовать только внутри пакета, снаружи недоступна
```

## Спецификаторы формата в Go

| Спецификатор | Тип                           | Пример кода                 | Вывод                       |
| ------------ | ----------------------------- | --------------------------- | --------------------------- |
| `%s`         | string                        | `fmt.Printf("%s", "Hello")` | `Hello`                     |
| `%q`         | string (в кавычках)           | `fmt.Printf("%q", "Hello")` | `"Hello"`                   |
| `%d`         | int                           | `fmt.Printf("%d", 42)`      | `42`                        |
| `%f`         | float                         | `fmt.Printf("%f", 19.99)`   | `19.990000`                 |
| `%.2f`       | float (2 знака после запятой) | `fmt.Printf("%.2f", 19.99)` | `19.99`                     |
| `%t`         | bool                          | `fmt.Printf("%t", true)`    | `true`                      |
| `%v`         | любой тип                     | `fmt.Printf("%v", 42)`      | `42`                        |
| `%+v`        | struct (с именами полей)      | `fmt.Printf("%+v", u)`      | `{Name:Ali Age:30}`         |
| `%T`         | тип значения                  | `fmt.Printf("%T", 3.14)`    | `float64`                   |
| `%%`         | знак процента                 | `fmt.Printf("%%")`          | `%`                         |
| `\n`         | новая строка                  | `fmt.Printf("a\nb")`        | `a` и `b` на разных строках |

## Краткое резюме

- Внутри функций в основном используйте **:=**, вне функций — **var**.
- Выбирайте var, когда хотите указать тип или начать с нулевого значения.
- Преобразования типов всегда явные.
- Неиспользуемые переменные не компилируются; при необходимости используйте \_.
