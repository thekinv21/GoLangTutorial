# Операторы в Go

В Go есть те же операторы, что и в большинстве других языков

## Арифметические операторы

- **Сложение:** +
- **Вычитание:** -
- **Умножение:** \*
- **Деление:** /
- **Остаток от деления:** %

## На что обратить внимание:

#### Чтобы получить дробный результат деления, оба операнда должны быть одного (дробного) типа

```bash
fmt.Println(7.0 / 2) ---> Результат: 3.5

fmt.Println(float64(a) / float64(b)) ---> Результат: 3.5
```

#### При целочисленном делении отрицательного числа результат округляется к нулю.

```bash
fmt.Println(-7 / 2) ---> Результат: -3 (округление к нулю)
```

#### При взятии остатка знак результата берётся от левого операнда.

```bash
fmt.Println(-7 % 2) ---> Результат: -1 (знак от левого числа)
```

#### Разные типы смешивать нельзя

```bash
var x int = 5
var y float64 = 2.5

// fmt.Println(x + y) // ОШИБКА: mismatched types

fmt.Println(float64(x) + y) // 7.5
```

## Операторы сравнения (результат bool)

- **Равно:** ==
- **Не равно:** !=
- **Больше:** >
- **Меньше:** <
- **Больше или равно:** >=
- **Меньше или равно:** <=

```bash
a, b := 7, 2

fmt.Println(a == b, a != b, a > b, a < b, a >= b, a <= b)
// false true true false true false
```

## Логические операторы

- **И:** &&
- **ИЛИ:** ||
- **НЕ:** !

```bash
t, f := true, false

fmt.Println(t && f) // false (И)
fmt.Println(t || f) // true  (ИЛИ)
fmt.Println(!t)     // false (НЕ)

```

### Важные заметки:

Короткое замыкание: если левая часть && равна false, правая часть не вычисляется

```bash
var p *int

if p != nil && *p > 0 { // p равен nil, поэтому *p не выполняется, паники нет
  fmt.Println("положительное")
}
```

## Операторы присваивания

```bash
n := 10
n += 5  // 15
n -= 3  // 12
n *= 2  // 24
n /= 4  // 6
n %= 4  // 2

fmt.Println(n) // 2

// ++ и -- это инструкции, а не выражения
n++
n--


// m := n++   // ОШИБКА
// ++n        // ОШИБКА, префиксной формы нет
```

### ЗАМЕТКА:

В Go НЕТ тернарного оператора (?:), поэтому приходится писать if/else

```bash

a, b := 7, 2

max := a

if b > a {
	max = b
}

fmt.Println(max) // 7
```
