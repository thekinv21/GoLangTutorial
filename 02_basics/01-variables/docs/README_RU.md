# Переменные в Go

Go — статически типизированный язык: тип каждой переменной известен на этапе компиляции и потом не меняется. Объявить переменную можно несколькими способами.

## 1. Объявление через var:

```bash
var fullName string = "Vadim Kiniabaev"
var age int = 26
```

- Если задать начальное значение, Go сам выведет тип (type inference):

```bash
var fullName = "Vadim Kiniabaev" (определяется как string)
var age = 21 (определяется как integer)
```

## 2. Короткое объявление: :=

- Самый распространённый способ внутри функций

```bash
 message := "Hello World"
 title := "Full-Stack Developer"
```

#### ПРИМЕЧАНИЕ:

:= можно использовать только внутри функции. На уровне пакета (вне функций) нужно использовать var.

## 3. Нулевые значения (zero values)

Переменные, объявленные без значения, автоматически получают нулевое значение своего типа. В Go не бывает «неопределённых» переменных:

| Тип                                           | Нулевое значение |
| --------------------------------------------- | ---------------- |
| `int`, `float64`                              | `0`              |
| `string`                                      | `""`             |
| `bool`                                        | `false`          |
| pointer, slice, map, channel, func, interface | `nil`            |

### Примеры

```bash
 var message string -> ""

 var price float64 -> 0

 var count int -> 0

 var isActive bool -> false
```

## 4. Множественное объявление

```bash
 var a,b,c int = 1,2,3

 var (
	user = "admin"
	port = 4200
	debug = false
 )
```

Обменять значения тоже можно в одну строку:

```bash
 a,b = b,a
```

## 5. На что обратить внимание

**Неиспользуемая переменная — это ошибка компиляции.** Go делает так намеренно, чтобы код оставался чистым:

```bash
x := 5   // Если x нигде не используется: ошибка "declared and not used"
```

### ПРИМЕЧАНИЕ:

Чтобы намеренно проигнорировать значение, используется \_ (blank identifier):

```bash
_, err := strconv.Atoi("123") // преобразованное число не используется, проверяется только ошибка
```

- **:=** требует хотя бы одну новую переменную. Если все переменные слева уже существуют, будет ошибка; если хотя бы одна новая, остальным просто присваивается значение.

- **Затенение (shadowing):** Использование := во внутреннем блоке не меняет внешнюю переменную, а создаёт новую:

```bash
x := 1

if true {
	x := 2 // новая x, не влияет на внешнюю
	fmt.Println(x) // здесь значение 2
}

// здесь значение 1, потому что **:=** во внутреннем блоке не меняет внешнюю переменную, а только создаёт новую
fmt.Println(x)
```

## 6. Видимость (Exported / Unexported)

Для переменных уровня пакета важна заглавная буква:

```bash
var Version string = "v1" // можно использовать как внутри, так и вне пакета

var newVersion string = "v2" // можно использовать только внутри пакета, снаружи недоступна
```

## Краткое резюме

- Внутри функций в основном используйте **:=**, вне функций — **var**.
- Выбирайте var, когда хотите указать тип или начать с нулевого значения.
- Преобразования типов всегда явные.
- Неиспользуемые переменные не компилируются; при необходимости используйте \_.
