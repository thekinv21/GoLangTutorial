# Базовые типы в Go

- **Целые числа:** int, int8, int16, int32, int64, для беззнаковых uint, uint8 (byte) и т. д.
- **Дробные:** float32, float64
- **Текст:** string, для одного символа rune (псевдоним int32)
- **Логический:** bool
- **Комплексные числа:** complex64, complex128

## Целые числа (знаковые)

| Тип              | Размер      | Минимум                    | Максимум                   |
| ---------------- | ----------- | -------------------------- | -------------------------- |
| `int8`           | 8 бит       | -128                       | +127                       |
| `int16`          | 16 бит      | -32 768                    | +32 767                    |
| `int32` (`rune`) | 32 бит      | -2 147 483 648             | +2 147 483 647             |
| `int64`          | 64 бит      | -9 223 372 036 854 775 808 | +9 223 372 036 854 775 807 |
| `int`            | 32 / 64 бит | Зависит от платформы       | Зависит от платформы       |

## Целые числа (беззнаковые)

| Тип              | Размер      | Минимум | Максимум                          |
| ---------------- | ----------- | ------- | --------------------------------- |
| `uint8` (`byte`) | 8 бит       | 0       | 255                               |
| `uint16`         | 16 бит      | 0       | 65 535                            |
| `uint32`         | 32 бит      | 0       | 4 294 967 295                     |
| `uint64`         | 64 бит      | 0       | 18 446 744 073 709 551 615        |
| `uint`           | 32 / 64 бит | 0       | Зависит от платформы              |
| `uintptr`        | 32 / 64 бит | 0       | Достаточно для хранения указателя |

## Числа с плавающей точкой

| Тип       | Размер | Диапазон (примерно)   | Точность      |
| --------- | ------ | --------------------- | ------------- |
| `float32` | 32 бит | ±1.18e-38 … ±3.4e38   | ~6-7 знаков   |
| `float64` | 64 бит | ±2.23e-308 … ±1.8e308 | ~15-16 знаков |

## Комплексные числа

| Тип          | Размер  | Описание                                  |
| ------------ | ------- | ----------------------------------------- |
| `complex64`  | 64 бит  | Действительная и мнимая части — `float32` |
| `complex128` | 128 бит | Действительная и мнимая части — `float64` |

## Другие типы

| Тип      | Значения                               | Нулевое значение |
| -------- | -------------------------------------- | ---------------- |
| `bool`   | `true` / `false`                       | `false`          |
| `string` | Текст в UTF-8 (неизменяемый)           | `""`             |
| `byte`   | Псевдоним для `uint8`                  | `0`              |
| `rune`   | Псевдоним для `int32` (символ Unicode) | `0`              |

> Примечание: нулевое значение всех числовых типов — `0`. Границы можно получить из пакета `math`: `math.MaxInt8`, `math.MinInt64`, `math.MaxUint32`, `math.MaxFloat64`.
